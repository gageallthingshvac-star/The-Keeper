# Fineframe music library

The background music [Fineframe](https://github.com/zcxy-dev/fineframe) offers new edits: 40 instrumental tracks, 8 for each mood. The app downloads a track from this repository's [releases](https://github.com/zcxy-dev/fineframe-music/releases) only when an edit plays it or someone previews it, and checks it against the SHA-256 listed here.
