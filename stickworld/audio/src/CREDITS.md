# Audio credits: HVAC package-unit Short

Every file in this folder is a real recording or a light edit of one (trimmed, normalised or re-encoded).
None of them is synthesised here.
Each license was checked against the credit or license file that ships with the source repository.
Copies of those files are in `licenses/`.
All GitHub sources are pinned to the exact commit the files were downloaded from.

## Notes and caveats

- **Origin pages not checked.** From this environment I could not open the original Freesound, OpenGameArt, SoundBible or FreePD pages; the network policy blocks them.
  Each license above comes from the source repository's own credit or attribution file, saved in `licenses/`.
  Before monetising, it is worth clicking the Freesound links for the three CC BY files and the FreePD capture for the music.
- **Possible false Content ID claims on the music.** Some of Rafael Krux's other tracks are also distributed under CC BY 4.0 (filmmusic.io) or sold commercially.
  If YouTube shows a Content ID claim, dispute it: cite CC0 and link the archive.org capture.
  A courtesy credit costs nothing and is recommended.
- **Edited derivatives.** The hillbomb-sf and leonvanzyl/skills files are edits of Freesound HQ previews (lossy), not the original uploads.
  The quality is fine for a Short.
- **Crickets license.** `crickets.ogg` is labelled "Public Domain" (SoundBible), not formally CC0.
  A CC0 alternative is "Crickets At Night - Raw sound" by Defelozedd94 (fs 522299), available as `public/assets/audio/amb/amb_park_night.mp3` in hillbomb-sf; it is not saved here.
- **Extra files.** `truck_start.mp3` and `hum_fan.ogg` are optional extras beyond the requested slots.
- **Long files need trimming or looping:** `crickets.ogg` (49 s), `hum.mp3` (11 s loop), `hum_fan.ogg` (8 s), `fizz.ogg` (3.6 s), `brake_squeak.mp3` (4 s), `truck.mp3` (3.9 s loop).
